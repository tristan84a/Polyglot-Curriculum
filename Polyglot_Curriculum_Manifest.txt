POLYGLOT CURRICULUM MANIFEST

Status: Current
Encoding: UTF-8

1. PURPOSE

This manifest is the compact progress and allocation record for the
Polyglot curriculum repository.

It does not define pedagogy. The Polyglot Curriculum Charter governs
system-wide curriculum design, and each language syllabus governs that
language's canonical sequence. The language CSV is authoritative for
cards that actually exist and for their row order.

The manifest records stable language ID allocations, current card-file
extent, syllabus version, and a concise curriculum-frontier checkpoint.
Routine card generation may update this manifest without amending the
Charter or a language syllabus.

2. ID ALLOCATION

Polyglot currently uses integer language blocks of 100,000 IDs.

Language    Reserved ID range    Current used IDs     Current cards
French      100000-199999        100000-100599        600
German      200000-299999        200000-200139        140
Japanese    300000-399999        300000-300059        60
Polish      400000-499999        400000-400050        51
Hungarian   500000-599999        500000-500035        36
Turkish     600000-699999        600000-600049        50

These ranges are reservations, not curriculum-size targets. Unused IDs
within a language's block remain reserved for that language. Stable IDs
must not be reused or renumbered merely because curriculum units are
later split, merged, reordered, or reclassified.

Before assigning an ID block to a new language, consult this manifest
and reserve a new non-overlapping range deliberately.

4. MAINTENANCE RULES

Update this manifest when:
- a new language receives an ID allocation;
- a language card CSV is created;
- routine card generation materially advances a curriculum frontier;
- a syllabus version changes in a way relevant to the checkpoint;
- an ID allocation convention changes.

Do not use this manifest to replace the language syllabus or CSV.
For routine extension, the relevant syllabus and current language CSV
remain the primary sources. The manifest is a checkpoint and
cross-language allocation record.

Card counts are descriptive only. They are not completion quotas and do
not determine when a syllabus unit is established.
